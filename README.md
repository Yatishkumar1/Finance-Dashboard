# 💰 Finance Dashboard UI

A clean and interactive **Finance Dashboard** built using **HTML, CSS, and JavaScript**.
This project demonstrates frontend development skills including UI design, state management, data visualization, and user interaction.

---

## 🚀 Features

### 📊 Dashboard Overview

* Total Balance, Income, and Expenses summary cards
* Balance trend visualization (Line Chart)
* Spending breakdown (Pie Chart)

### 💳 Transactions Section

* View all transactions with:

  * Date
  * Amount
  * Category
  * Type (Income/Expense)
* Features:

  * Search by category
  * Filter (Income/Expense)
  * Delete transactions (Admin only)

### 🔐 Role-Based UI

* **Viewer** → Can only view data
* **Admin** → Can add & delete transactions
* Role switching via dropdown

### 🧠 Insights Section

* Highest spending category
* Monthly income vs expense comparison
* Savings calculation
* Smart financial observations

### 🌙 Dark Mode

* Toggle between Light & Dark theme
* Theme persistence using localStorage

### 📱 Responsive Design

* Fully responsive layout
* Works across desktop, tablet, and mobile devices

---

## 🛠️ Tech Stack

* HTML5

* JavaScript (Vanilla JS)
